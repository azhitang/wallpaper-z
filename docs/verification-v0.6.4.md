# 壁纸z v0.6.4 验证记录

日期：2026-11-10。应用 ID：`com.wallpaperz.app`，versionCode：15。

## 新增设置

每个主题在“定时”模式下可选择“视频播放时长”：

- 播完切换：视频静音播放一遍后换下一张；原主题和新主题默认使用这一选项。
- 跟随间隔：视频与照片使用同一个轮播间隔，短视频静音循环，长视频到时切换。

亮屏／解锁模式继续由原有屏幕事件切换。播放中修改选项会更新当前视频的重复模式与调度方式，保留当前素材和整轮记录，不重新开始队列。通知和时间选择面板同步显示对应语义。

## 本地验证

- 正式 Release 构建、Android 测试包构建通过；37 项单元测试全部通过，Lint 0 错误、9 警告。
- API 37 / Android 17 模拟器上 9 项播放和设置测试整组通过，耗时约 204 秒。
- 使用真实 3 秒视频循环，实际等待一个完整的 1 分钟间隔，确认视频没有在第一次播完时切换。
- 使用真实 70 秒视频，确认在 60～65 秒之间切换到照片，提前结束当前长视频。
- 播放中从播完切换改为跟随间隔，再改回播完切换，当前播放代次与整轮记录保留，随后按实际播放结束事件切换。
- UI 验证主题独立保存、间隔标题联动；回归视频播完切换、熄屏继续播放、单视频重复轮次，以及解锁事件只切换一次。
- 旧数据没有视频时长字段时默认保留播完切换；序列化恢复不丢失顺序和进度。

70 秒素材只位于 Android 测试资源中，主应用不内置视频。测试使用正式签名的本地 Release，发布包仍由 GitHub Actions 使用同一密钥构建。
